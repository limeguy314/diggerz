DIGGERZ CUSTOM HATS

Put custom hat PNG files in this folder. The multiplayer server automatically scans this folder.

Recommended image size: 56 x 50 pixels (the same native canvas size as the default Diggerz head).
Use transparent PNGs. The custom hat system preserves the PNG's 56x50 canvas and uses it as a native wearable.

Names are taken from the filename. Example:
  wizard_hat.png  ->  Wizard Hat

Files beginning with an underscore are ignored.
The built-in noob_hat.png is reserved for the built-in Noob Hat and is not loaded as a duplicate custom item.

Use ../custom-hat-maker.html to create/fix a 56x50 PNG.
