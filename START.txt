DIGGERZ MULTIPLAYER BETA

Render settings:
Runtime: Node
Build Command: npm install
Start Command: npm start
Plan: Free

The game is served by server.js. Do not use the old multiplayer HTML from an earlier build.
Use the new diggerz-multiplayer.html in this folder.

There is no map selector. The default public URL puts beta testers in the same room.
Optional room testing uses ?room=test, but everyone must use the same room URL to see each other.

Required multiplayer behavior:
- same map for all players in a room
- mining sync
- block placement sync
- inventory updates after mining
- visible/moving players and names
- multiplayer chat
- room reset to the original map when the last player leaves
